# Modelo — notificação de violação de dados à APD

| Campo | Valor |
|---|---|
| Ticket | KAM-113 |
| Runbook | [`../resposta_incidentes.md`](../resposta_incidentes.md) §9 |
| Prazo interno | PRZ-4 do runbook §2 — *boa prática; obrigação a confirmar por parecer* |
| Estado | **Modelo. Não enviar sem revisão do advogado, salvo a excepção do fundador do §9.4 do runbook** *(a confirmar por parecer)*. A APD pode ter formulário próprio (NÃO VERIFICADO): este modelo é o **conteúdo** a levar, não o formulário |

> **Antes de preencher.**
> 1. **Quem notifica é a decisão D9** e está aberta: este modelo está escrito **do ponto de vista
>    da KAMBÁ**. Se o parecer disser que cada PME notifica, entrega-se o texto às PMEs.
> 2. **Nenhum dado pessoal de titulares, nenhum conteúdo de mensagens, nenhum segredo.**
>    Identificadores técnicos opacos e contagens, sim; valores, não.
> 3. **Não se afirma que há obrigação legal**, nem se cita coima. O texto diz o que aconteceu.
> 4. Tempo de preenchimento alvo: ≤ 30 min com o §8 do runbook (avaliação) já respondido
>    (*proposta*; medido no exercício).

Marcadores `[A PREENCHER: …]` são para substituir; o que sobrar no texto impede o envio.
